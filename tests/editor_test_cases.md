## 测试用例 1：完整的写作流程测试

### 测试目标
验证基本的写作编辑流程，包括项目加载、章节管理、富文本编辑、保存等核心功能。

### 前置条件
1. 已登录用户账号 (user_id: 1, testuser)
2. 数据库中已有测试项目 "奇幻冒险小说" (project_id: 1)
3. 项目中已有3个章节，内容包含HTML格式和纯文本

### 测试步骤

#### 1.1 项目加载测试
- **步骤**：访问编辑器页面 `/editor/1`
- **预期结果**：
  - 左侧显示项目标题 "奇幻冒险小说"
  - 显示章节数量 "3 Chapters"
  - 章节列表显示3个章节
  - 自动选中第一个章节并显示内容

#### 1.2 章节列表显示测试
- **步骤**：查看左侧章节列表
- **预期结果**：
  - 显示 "Chapter 1: 序章：命运的开始"（高亮显示）
  - 显示 "Chapter 2: 第一章：魔法觉醒"
  - 显示 "Chapter 3: 第二章：冒险启程"
  - 当前章节显示蓝色指示点

#### 1.3 章节切换测试
- **步骤**：点击 "Chapter 2: 第一章：魔法觉醒"
- **预期结果**：
  - 章节2变为高亮状态
  - 编辑器内容切换为章节2的内容
  - 标题输入框显示 "第一章：魔法觉醒"
  - 字数统计正确更新

#### 1.4 富文本编辑测试 - 字体格式
- **步骤**：
  1. 在编辑器中选择部分文本
  2. 将字体改为 "Arial"
  3. 将字号改为 "五号"
- **预期结果**：
  - 选中文本字体变为 Arial
  - 字号变为五号
  - 工具栏显示当前选择的字体和字号

#### 1.5 富文本编辑测试 - 文本样式
- **步骤**：
  1. 选中一段文本
  2. 点击 "B"（粗体）
  3. 点击 "I"（斜体）
  4. 点击 "U"（下划线）
- **预期结果**：
  - 文本变为粗体
  - 文本变为斜体
  - 文本添加下划线
  - 可以同时应用多个样式

#### 1.6 富文本编辑测试 - 文本颜色和高亮
- **步骤**：
  1. 选中文本
  2. 选择颜色 "#be123c"（红色）
  3. 选择高亮颜色 "#fef3c7"（黄色）
- **预期结果**：
  - 文本颜色变为红色
  - 文本背景高亮为黄色
  - 工具栏显示当前选择的颜色

#### 1.7 富文本编辑测试 - 对齐和列表
- **步骤**：
  1. 将光标放在一段文本
  2. 点击 "中"（居中）
  3. 点击列表图标（无序列表）
- **预期结果**：
  - 文本居中对齐
  - 文本转换为无序列表

#### 1.8 标题编辑测试
- **步骤**：在标题输入框中输入 "新标题：测试章节"
- **预期结果**：
  - 标题立即更新
  - 左侧章节列表中的标题同步更新
  - 自动保存触发（2秒后）

#### 1.9 自动保存测试
- **步骤**：
  1. 在编辑器中输入一些新文本
  2. 等待2秒
  3. 观察顶部状态栏
- **预期结果**：
  - 2秒后状态显示 "Saving..."
  - 保存成功后显示 "Saved"（绿色）
  - 保存时间更新

#### 1.10 手动保存测试
- **步骤**：点击顶部右侧的保存按钮（软盘图标）
- **预期结果**：
  - 取消自动保存的等待
  - 立即触发保存
  - 状态显示 "Saved"

#### 1.11 字数统计测试
- **步骤**：
  1. 在编辑器中输入 "This is a test paragraph with multiple words."
  2. 查看底部字数统计
- **预期结果**：
  - 显示正确的单词数（如 "8 words"）
  - HTML标签不计入字数
  - 空格和标点正确处理

#### 1.12 创建新章节测试
- **步骤**：点击左下角 "New Chapter" 按钮
- **预期结果**：
  - 创建新章节 "Chapter 4"
  - 自动切换到新章节
  - 编辑器为空
  - 章节列表显示新章节

## 测试用例 2：时间轴功能完整测试

### 测试目标
验证时间轴相关的所有功能，包括AI生成、标记事件、编辑、跳转、删除、导出等。

### 前置条件
1. 已登录并进入项目编辑器 (project_id: 1)
2. 项目中已有多个章节
3. 编辑器中有可选择的文本内容

### 测试步骤

#### 2.1 打开时间轴抽屉测试
- **步骤**：点击顶部右侧的 "Timeline" 按钮
- **预期结果**：
  - 右侧时间轴抽屉从右侧滑入
  - 按钮变为激活状态（蓝色背景）
  - 主编辑区向右缩进，留出时间轴空间

#### 2.2 时间轴初始状态测试
- **步骤**：查看时间轴抽屉内容
- **预期结果**：
  - 显示初始事件 "Project Start"
  - 时间轴垂直连线显示
  - 事件卡片正常显示（年、标题、描述）

#### 2.3 AI生成时间轴事件测试
- **步骤**：
  1. 点击 "AI Generate" 按钮
  2. 等待生成完成
- **预期结果**：
  - 按钮显示 "Generating..." 和旋转图标
  - 1.5秒后生成多个事件（每个章节一个）
  - 事件按照章节顺序排列
  - 事件有不同颜色标识
  - 按钮恢复 "AI Generate"

#### 2.4 标记选中文本为事件测试
- **步骤**：
  1. 在编辑器中选中一段文本（如 "主角发现了古老的魔法书"）
  2. 点击顶部 "Mark Event" 按钮
- **预期结果**：
  - 时间轴自动打开（如果未打开）
  - 新事件添加到时间轴
  - 事件标题为 "Marked Event"
  - 事件描述为选中的文本（最多100字符）
  - 事件关联到当前章节

#### 2.5 编辑时间轴事件测试
- **步骤**：
  1. 点击时间轴中的某个事件卡片
  2. 编辑年份输入框：输入 "Chapter 1"
  3. 编辑标题输入框：输入 "魔法觉醒时刻"
  4. 编辑描述文本域：输入 "主角首次感受到魔法力量"
- **预期结果**：
  - 所有字段可以正常编辑
  - 输入框实时更新
  - 保存后内容持久化（虽然目前是前端状态）

#### 2.6 跳转到章节测试
- **步骤**：点击时间轴事件卡片（不是输入框）
- **预期结果**：
  - 自动切换到事件关联的章节
  - 编辑器显示该章节内容
  - 章节列表高亮对应章节
  - 时间轴保持打开状态

#### 2.7 删除时间轴事件测试
- **步骤**：
  1. 将鼠标悬停在事件卡片上
  2. 点击底部出现的删除图标（垃圾桶）
- **预期结果**：
  - 事件从时间轴中删除
  - 其他事件正常显示
  - 删除操作立即生效

#### 2.8 导出时间轴图片测试
- **步骤**：点击 "Export Image" 按钮
- **预期结果**：
  - 触发图片导出（需要html2canvas库）
  - 下载图片文件
  - 文件名包含项目标题
  - 图片包含完整的时间轴内容

#### 2.9 关闭时间轴抽屉测试
- **步骤**：点击时间轴抽屉右上角的 X 图标
- **预期结果**：
  - 抽屉向右滑出隐藏
  - 主编辑区恢复全宽
  - Timeline 按钮恢复未激活状态

#### 2.10 时间轴空状态测试
- **步骤**：
  1. 删除所有时间轴事件
  2. 查看空状态显示
- **预期结果**：
  - 显示提示文字 "No events yet."
  - 显示使用说明
  - AI Generate 和 Export 按钮仍然可用

## 测试用例 3：边界情况和错误处理测试

### 测试目标
验证系统在边界情况和错误场景下的稳定性。

### 前置条件
1. 已登录并进入编辑器
2. 准备测试不同的数据状态

### 测试步骤

#### 3.1 空项目测试
- **步骤**：访问一个没有任何章节的项目
- **预期结果**：
  - 显示提示 "Select a chapter to start writing"
  - 显示 "Create your first chapter" 按钮
  - 点击按钮可以创建第一个章节

#### 3.2 大量文本测试
- **步骤**：
  1. 在编辑器中粘贴大量文本（>10000字）
  2. 应用多种格式
  3. 测试自动保存
- **预期结果**：
  - 编辑器能正常显示大量文本
  - 滚动流畅
  - 自动保存正常工作
  - 字数统计准确

#### 3.3 HTML内容处理测试
- **步骤**：
  1. 编辑包含复杂HTML的内容（来自测试数据）
  2. 切换章节
  3. 保存并重新加载
- **预期结果**：
  - HTML正确渲染
  - 切换章节时内容正确同步
  - 保存后HTML内容完整保留

#### 3.4 快速连续输入测试
- **步骤**：
  1. 快速连续输入文本（每秒>10个字符）
  2. 观察自动保存行为
- **预期结果**：
  - 防抖功能正常工作（2秒延迟）
  - 不会频繁触发保存请求
  - 最后一次输入后2秒才保存

#### 3.5 网络错误处理测试（模拟）
- **步骤**：
  1. 打开浏览器开发者工具
  2. 设置网络为离线模式
  3. 尝试保存文档
- **预期结果**：
  - 显示错误状态 "Unsaved Changes"（红色）
  - 控制台输出错误信息
  - 恢复网络后可以重新保存

#### 3.6 多个章节快速切换测试
- **步骤**：快速连续点击不同章节（每秒切换2-3次）
- **预期结果**：
  - 每次切换都能正确显示对应内容
  - 没有内容混乱
  - 编辑器状态正确同步

#### 3.7 清除格式测试
- **步骤**：
  1. 选择包含多种格式的文本
  2. 点击 "清除" 按钮
- **预期结果**：
  - 所有格式被清除
  - 文本恢复为默认格式
  - 不再包含HTML标签

#### 3.8 标题为空测试
- **步骤**：清空章节标题输入框
- **预期结果**：
  - 可以保存为空标题
  - 章节列表显示 "Untitled Chapter"
  - 系统不会崩溃

#### 3.9 特殊字符测试
- **步骤**：在标题和内容中输入特殊字符：`<script>alert('xss')</script>` 和 emoji 😀
- **预期结果**：
  - 特殊字符正常显示
  - 没有XSS漏洞
  - emoji正常渲染

#### 3.10 时间轴大量事件测试
- **步骤**：
  1. 生成20+个时间轴事件
  2. 滚动时间轴
  3. 测试所有事件功能
- **预期结果**：
  - 滚动流畅
  - 所有事件正确显示
  - 删除、编辑、跳转功能正常

## 测试用例 4：完整工作流综合测试

### 测试目标
模拟真实用户使用场景，测试完整的工作流程。

### 前置条件
1. 使用测试项目 "现代都市小说" (project_id: 2)
2. 项目有5个章节，内容多样

### 测试步骤

#### 4.1 开始新项目写作流程
- **步骤**：
  1. 打开编辑器页面
  2. 查看项目信息
  3. 选择第一个章节开始编辑
- **预期结果**：所有信息正确加载和显示

#### 4.2 完整章节创作流程
- **步骤**：
  1. 编辑标题为 "第一章：都市中的魔法"
  2. 输入正文内容（包含多段文本）
  3. 对不同段落应用不同格式
  4. 使用多种字体和颜色
  5. 添加列表和对齐
- **预期结果**：
  - 所有编辑操作正常
  - 格式正确应用
  - 内容实时保存

#### 4.3 时间轴管理流程
- **步骤**：
  1. 打开时间轴
  2. 使用AI生成初始时间轴
  3. 选中关键文本并标记为事件
  4. 编辑事件信息
  5. 通过事件跳转到相关章节
- **预期结果**：所有时间轴功能协调工作

#### 4.4 多章节协作编辑流程
- **步骤**：
  1. 在多个章节间切换
  2. 编辑每个章节
  3. 创建新章节
  4. 重新排序（如果支持）
- **预期结果**：
  - 章节切换流畅
  - 每个章节的状态独立保存
  - 创建新章节成功

#### 4.5 导出和分享流程
- **步骤**：
  1. 完成多个章节编辑
  2. 生成完整时间轴
  3. 导出时间轴为图片
  4. 返回项目列表
- **预期结果**：
  - 导出成功
  - 图片质量良好
  - 可以正常返回
