本测试数据脚本提供了**完整的测试数据**，可以测试编辑器的所有功能，**无需修改前端代码**。所有测试都基于数据库中的实际数据。

- **章节数**: 13

### 边界情况测试
使用**项目3**和**项目4**，包含各种特殊场景和边界情况。

### 性能测试
使用**项目3的章节13**，包含大量重复文本，可以测试编辑器性能。

## 注意事项

1. **无需修改前端代码**：所有测试都可以通过现有数据库数据完成
2. **测试账号**：使用 `testuser` 账号登录
3. **数据导入**：执行 `test_data.sql` 脚本导入所有测试数据
4. **数据更新**：如果数据已存在，脚本会自动更新（使用 `ON DUPLICATE KEY UPDATE`）
5. **生产环境**：这些是测试数据，不要在生产环境使用

## 测试流程建议

1. **导入数据**: 执行 `test_data.sql`
2. **登录账号**: 使用 testuser 登录
3. **基础测试**: 访问 `/editor/1` 进行基础功能测试
4. **格式测试**: 访问 `/editor/2` 测试所有格式功能
5. **边界测试**: 访问 `/editor/3` 和 `/editor/4` 测试边界情况
6. **综合测试**: 按照测试用例文档执行完整测试流程
